### Pricing

- Price rises with distance from the nearest top-100 US city by population.
- Each builder changes the original base price slightly, so sites differ.
- State the price on the landing page, beside an instant quote that can be texted, messaged, or emailed.
- The base price was not provided; get it from the team before building.
