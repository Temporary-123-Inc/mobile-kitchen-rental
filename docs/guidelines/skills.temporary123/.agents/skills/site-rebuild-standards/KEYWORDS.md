# Super 9 Keywords

The nine keyword categories for every rebuilt site. A DA over 25 H1 draws its 4–9 keyword phrases from this list (see [SKILL.md](SKILL.md)). Each category lists the core terms; weave in its modifiers naturally.

**Shared modifiers (all nine):** trailer rentals, trailers for rent, trailer leasing, temporary facilities, modular, mobile, temporary, portable, emergency.
